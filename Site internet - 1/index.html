Estrutura e Funcionamento da Internet

A internet nos dias atuais, está presente na vida de praticamente todas as pessoas e é essencial entendê-la para que façamos bom uso. Ela consiste num conjunto de servidores ligados entre si aos quais qualquer pessoa se pode ligar de modo a aceder à informação existente em qualquer um deles. Por vezes costuma-se dizer que é uma rede de redes. É um sistema global de redes de computadores interligadas que utiliza o conjunto de protocolos TCP/IP para permitir a comunicação e o compartilhamento de dados em todo o

A internet é composta por mais de 20 milhões de servidores nos quais estão alojadas as páginas e quase tudo o que é possível encontrar na Internet. Cada servidor têm um ou mais domínios alojados e cada domínio pode ser composto por um número variável de páginas e informação. A informação contida nas páginas faz muitas vezes referência a informação de outras páginas. Cada servidor têm associado a si um ou mais endereços IP

Como um Usuário se Conecta à Internet
Para um usuário particular se conectar à Internet é preciso uma linha telefônica, um microcomputador com modem (aparelho que permite a transmissão de dados por telefone) e um programa de acesso à rede: os principais são:
  • Navigator
  • Netscape
  • Internet Explorer
  • Microsoft
O passo seguinte é se cadastrar em um provedor de acesso à rede, de preferência um provedor local (na própria cidade), para não pagar ligações interurbanas. Ao filiar-se, o novo cliente recebe um nome (username), uma senha (password) e um endereço na Internet. No endereço eletrônico - ricardob@embratel.net.br, por exemplo: o nome do usuário e a identificação do provedor escolhido são separados pelo sinal "@" (arroba).
